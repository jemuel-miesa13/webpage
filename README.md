IMAGE FORMAT HANDLING
For ss1, ss2, zc, mlbb, and zt, the website tries the .jpg version first and then the .png version. Only one format is required for each asset. Game icons have no emoji or generic icon fallback; when an icon file is missing, its icon slot is hidden.

GAMEPLAY VIDEO
- battle.mp4 is displayed without native playback controls.
- The page attempts to autoplay with audio. Some browsers block autoplay with sound; in that case the video retries muted and the visitor can use the on-video Mute audio / Unmute audio button.
